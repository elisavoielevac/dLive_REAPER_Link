REAPER Connection

Enable OSC in REAPER. App sends to REAPER: 127.0.0.1:49101. REAPER feedback to app: 127.0.0.1:49102. Without feedback, marker naming may time out.

Scene Lists

The loaded scene list provides the names used for REAPER markers. Export saves an external copy without changing it. Import brings an external text file into the app as a new loaded scene list.

Saved Scene Lists

Saved scene lists are app-managed copies. Loading one replaces the currently loaded scene list used for marker names.
